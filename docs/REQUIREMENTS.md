## 5. 产品决策引用（已拍板 → `docs/DECISIONS.md`）

> 原「待拍板决策清单」中的产品层问题**已由用户拍板**，决策与默认假设固化于 **`docs/DECISIONS.md`**（Orchestrator 维护，已合并进 main）。
> **本清单不再作为待拍板项**，以下仅为引用摘要；任何与本表冲突的内容，一律以 `docs/DECISIONS.md` 为准。

### 已拍板决策（D1–D4，用户确认）

| # | 决策点 | 决策 |
|---|---|---|
| D1 | 支付方式 | **模拟支付**：无真实支付渠道，「支付成功」即模拟入账；订单/托管/结算状态机必须真实完整（pending payment → paid(escrow) → delivered → completed / refunded） |
| D2 | 货币单位 | **平台币 Credits（CR）**：整数，最小粒度 1；界面统一 `500 CR` 格式（tabular-nums），**不使用** USD/CNY/¥ 符号 |
| D3 | 注册验证 | 邮箱 + 密码注册，**免邮箱验证邮件**；密码最小长度 8 |
| D4 | 角色模型 | 注册选**主角色**；账号可**并存三种角色**并在个人中心切换；API 用角色集合表达（如 `roles: ["buyer","seller"]`） |

### 默认采纳的假设（A1–A6，用户未反对、先行实现）

| # | 决策点 | 默认值 |
|---|---|---|
| A1 | 大额充值阈值 | 单次充值 ≥ **100 CR** 需二次确认（显示充值后余额变化）；阈值集中配置 |
| A2 | 退款窗口 | 作品订单 **14 天**（未确认收货前可申请退款） |
| A3 | 托管放款 | 买家确认收货即放款；接单类验收期 **7 天**自动确认 |
| A4 | 提现到账时间 | **1–3 个工作日**，页面必须明示 |
| A5 | 手续费 | 下单显示含手续费总价；费率默认 **5%**（集中配置） |
| A6 | 演示数据 | 系统内置演示数据（示例作品、示例需求），保证空库可演示 |

> 其余产品级疑问（如演示链接他人设备可打开）继续由 #10 质量验收兜底，不在此列。
